QUESTIONS

FAQ

Answers to some of the most common questions.

When does The Dupe Event end?

The Dupe Event is live for a limited time and is scheduled to end on Monday, August 31, 2026. Check the countdown at the top of the website for the exact remaining time.

What is The Dupe Event?

The Dupe Event is a special Devs Anarchy event built around chaos and a unique server experience.

What version does Devs Anarchy use?

The server currently runs on Minecraft 26.2, with support for versions that can connect.

Can I play on Bedrock?

Bedrock support is currently coming soon. Don't worry—we haven't forgotten about Bedrock players! When Bedrock is able to play, we'll host a special event and giveaway to celebrate.

Can cracked players join?

Cracked account support is currently unavailable. When cracked accounts are able to play again, we'll host a special event and giveaway to celebrate!

Are ranks available?

Ranks are currently coming soon. Planned ranks include VIP, MVP, ELITE, LEGEND and OVERLORD.
