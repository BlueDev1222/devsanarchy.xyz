# Devs Anarchy

Static website for GitHub Pages. No build or package installation required.

## Preview

Run `node preview.cjs`, then open http://127.0.0.1:4173.

## Dupe event

The dupe event section displays a full-width $50 funding goal using confirmed Tebex purchase totals. The old countdown has been removed. Discord is the source for event start announcements. See GOAL-SETUP.md for the integration.

Java and cracked support are advertised as requested. Website edits do not modify Minecraft server authentication or start an in-game event.

## Design

Homepage styling: assets/site.css. Supporting pages: assets/pages.css. Local vector artwork: assets/world.svg, reproducible with node artwork.cjs. Google Fonts have system fallbacks.

Existing policies and historical content are retained. Links to four missing store rank pages now lead to support.
